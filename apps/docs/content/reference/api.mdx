# HTTP API reference

All admin endpoints (`/api/*`) require RBAC. Send `Authorization: Bearer <api-key>` or a `mavio_sid`
cookie from an OIDC login. `/mcp` and `/mcp/sse` accept unauthenticated MCP frames only in dev-open
mode.

```json
// Non-MCP error shape
{ "statusCode": 403, "error": "authz denied: missing tool:invoke on server=petstore" }

// MCP error shape (JSON-RPC 2.0)
{ "jsonrpc": "2.0", "id": 2, "error": { "code": -32001, "message": "server not found: petstore" } }
```

| Code | Meaning |
|---|---|
| `-32001` | Server / tool not found |
| `-32002` | Server not approved (import pending or rejected) — see [ADR-021](/security/import-approval) |
| `-32003` | RBAC denied |
| `-32010` | Circuit breaker open |
| `-32011` | Rate limit exceeded |
| `-32020` | Upstream consent required |
| `-32000` | Unexpected upstream error |

## MCP data plane

| Route | Notes |
|---|---|
| `POST /mcp` | Any MCP JSON-RPC frame. `?sid=<uuid>` fans onto an SSE session (responds `202`). |
| `GET /mcp/sse` | First frame `event: endpoint` / `data: /mcp?sid=<uuid>`; then `message` / `notification` / 15s keep-alive. |
| `WS /mcp/ws` | Full-duplex; correlated responses; 15s ping. |

## Imports

| Method | Path | Body |
|---|---|---|
| POST | `/api/imports/openapi` | `{ id, url?, path?, baseUrl?, workspaceId, projectId, upstreamOAuthProvider? }` |
| POST | `/api/imports/sql` | `{ id, dsn, tables?, readOnly?, workspaceId, projectId, upstreamOAuthProvider? }` |
| POST | `/api/imports/graphql` | `{ id, endpoint, headers?, auth?, selectionDepth?, upstreamOAuthProvider? }` |
| POST | `/api/imports/mcp` | `{ id, transport: stdio\|http\|sse, name?, upstreamOAuthProvider? }` |
| GET  | `/api/imports/pending` | — (list pending submissions) |
| POST | `/api/imports/:id/approve` | — |
| POST | `/api/imports/:id/reject` | `{ reason? }` |

Submit endpoints require `server:import.submit` (granted to `developer`, `admin`). Approve/reject
require `server:approve` (granted to `admin` only). Every submit lands
`approval_status='pending'` and does **not** invalidate the router — capabilities are snapshotted
so admins can preview tools before approving. On approve, the router cache invalidates and traffic
begins routing. Response payload includes `approvalStatus`. See
[Import approval](/security/import-approval) for the full flow.

The optional `upstreamOAuthProvider` is stored as `metadata.upstreamOAuthProvider`; the router
resolves a per-principal upstream credential before dispatch — see
[Upstream OAuth](/security/upstream-oauth). The web console exposes it on every import tab,
including the **MCP** tab (mirror a stdio/http/sse MCP server).
