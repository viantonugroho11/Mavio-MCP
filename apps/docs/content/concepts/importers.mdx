# Importers — turn anything into MCP

| Source | Package | Endpoint / CLI |
|---|---|---|
| OpenAPI (v3) | `@mavio/import-openapi` | `POST /api/imports/openapi` · `mavio import openapi` |
| SQL (Postgres) | `@mavio/import-sql` | `POST /api/imports/sql` · `mavio import sql` |
| GraphQL | `@mavio/import-graphql` | `POST /api/imports/graphql` · `mavio import graphql` |
| Existing MCP server | `@mavio/import-mcp` | `POST /api/imports/mcp` · `mavio import mcp` |

- **OpenAPI** — pulls operations, resolves `$ref`, maps parameters to a JSON-Schema `inputSchema`.
- **SQL** — introspects tables/columns/PK/FK; optional allowlist; read-only by default. Every table
  becomes one MCP tool (`analytics.select_events`); args map to `WHERE` clauses.
- **GraphQL** — introspection with `inputFields`, `enumValues`, deprecation flags; recursive
  `INPUT_OBJECT` expansion (cycle-guarded, depth 3); auto scalar+enum leaf selection.
- **MCP-mirror** — opens a `stdio`/`http`/`sse` transport, sends `initialize` + `tools/list`, and
  snapshots the result as a Mavio-managed server.

```bash
mavio import openapi --id petstore --url https://petstore3.swagger.io/api/v3/openapi.json
mavio import sql --id analytics --dsn postgres://reader:pw@wh:5432/analytics --tables events,users
mavio import graphql --id shopify --endpoint https://shop.example/graphql --auth secret://SHOP_TOKEN
mavio import mcp --id filesystem --stdio "npx -y @modelcontextprotocol/server-filesystem /tmp"
```

All four importers are available in the **web console** (Imports page → `OpenAPI` / `SQL` /
`GraphQL` / `MCP` tabs) as well as the CLI/API. Every import accepts an optional
`upstreamOAuthProvider` to tag the resulting server for per-principal upstream auth — see
[Upstream OAuth](/security/upstream-oauth).

### MCP-mirror over HTTP/SSE with custom headers

The MCP tab (and `POST /api/imports/mcp`) accepts arbitrary request **headers** for `http`/`sse`
transports — the same shape as a standard MCP client config. To mirror a header-authenticated
server:

```json
{
  "id": "workbench",
  "transport": {
    "type": "http",
    "baseUrl": "https://workbench-uat.amartha.id/mcp",
    "headers": { "x-workbench-api-key": "YOUR_API_KEY" }
  }
}
```

Headers are sent on every dispatch. For a rotating secret prefer the `auth` bearer field
(`secret://ENV`, resolved from env, never persisted); header values are stored as-is on the
descriptor.

See [CLI reference](/reference/cli) for every flag.
